## 環境起動手順

```bash
# 1. プロジェクトディレクトリに移動
cd C:\Users\kazum\DevWork\LifeGuardianII

# 2. Docker環境を起動
docker-compose up -d

# 3. ログを確認
docker-compose logs -f backend

# 4. アクセス確認
# バックエンドAPI: http://localhost:3001/health
# Neo4j Browser: http://localhost:7475
```

## 動作確認用コマンド

### PowerShellでのAPI確認
```powershell
# ヘルスチェック
Invoke-RestMethod -Uri "http://localhost:3001/health"

# Person一覧取得
Invoke-RestMethod -Uri "http://localhost:3001/api/persons" | ConvertTo-Json -Depth 3

# 新しいPerson作成
$newPerson = @{
    name = "テスト太郎"
    birthDate = "1960-01-01"
    currentHealthStatus = "良好"
    communicationAbility = "会話可能"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:3001/api/persons" -Method Post -Body $newPerson -ContentType "application/json"
```
