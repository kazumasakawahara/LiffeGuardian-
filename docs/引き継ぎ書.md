## プロジェクト概要

**プロジェクト名**: LifeGuardianⅡ（意思決定支援システム）
**作成日**: 2025年7月24日
**プロジェクトパス**: `C:\Users\kazum\DevWork\LifeGuardianII`

### プロジェクトの目的
認知症や意思疎通が困難な方々の過去の意思決定、好み、人生の歩みを記録・分析し、現在の意思決定を支援するシステムの開発。

## 技術スタック

- **フロントエンド**: React + TypeScript
- **バックエンド**: Node.js + Express + TypeScript
- **メインDB**: Neo4j 5.15 (グラフデータベース)
- **サブDB**: PostgreSQL 16 (認証・ログ管理)
- **キャッシュ**: Redis 7
- **ワークフロー自動化**: n8n
- **コンテナ**: Docker + Docker Compose
- **リバースプロキシ**: Nginx

## データモデル概要

### Neo4jノード（8種類）
1. **Person**: 本人情報
2. **Supporter**: 支援者（家族、医療従事者等）
3. **LifeEvent**: 人生の出来事
4. **Decision**: 意思決定記録
5. **Preference**: 好み・価値観
6. **Document**: 重要文書
7. **EmergencyInfo**: 緊急時情報
8. **AIInteraction**: AI対話記録

### リレーションシップ（9種類）
- HAS_SUPPORTER（本人→支援者）
- EXPERIENCED（本人→出来事）
- MADE_DECISION（本人→意思決定）
- HAS_PREFERENCE（本人→好み）
- その他5種類

## 環境セットアップ手順

1. **環境変数の設定**
   ```bash
   cd C:\Users\kazum\DevWork\LifeGuardianII
   copy .env.example .env
   ```

2. **Dockerコンテナの起動**
   ```bash
   # すべてのサービスを起動
   make up
   # または
   docker-compose up -d
   ```

3. **データベースの初期化**
   ```bash
   # スキーマとサンプルデータの投入
   make db-init
   make db-seed
   ```
