# LifeGuardian クイックスタートガイド

## 🚀 はじめに

このガイドでは、LifeGuardianプロジェクトをDockerで簡単に起動する方法を説明します。

## 📋 前提条件

以下のソフトウェアがインストールされている必要があります：

- Docker Desktop（Windows/Mac）またはDocker Engine（Linux）
- Docker Compose（Docker Desktopには含まれています）
- Git
- Make（オプション、便利コマンド用）

## 🛠️ セットアップ手順

### 1. プロジェクトのクローン

```bash
git clone https://github.com/your-username/LifeGuardian.git
cd LifeGuardian
```

### 2. 初期セットアップ（Makeコマンド使用）

```bash
# 環境を初期化してビルド
make setup
```

### 2. 初期セットアップ（Makeコマンドなしの場合）

```bash
# 環境変数ファイルをコピー
cp .env.example .env

# Dockerイメージをビルド
docker-compose build

# サービスを起動
docker-compose up -d
```

### 3. データベースの初期化

```bash
# Makeコマンド使用
make db-init
make db-seed

# または手動で
docker-compose exec neo4j cypher-shell -u neo4j -p lifeguardian2024 < database/schema/setup-all.cypher
```

## 🌐 アクセスURL

サービスが起動したら、以下のURLにアクセスできます：

| サービス | URL | 用途 |
|---------|-----|------|
| フロントエンド | http://localhost:3000 | メインアプリケーション |
| バックエンドAPI | http://localhost:3001 | API（開発用） |
| Neo4j Browser | http://localhost:7474 | グラフDB管理 |
| n8n | http://localhost:5678 | ワークフロー自動化 |
| Adminer | http://localhost:8080 | PostgreSQL管理 |
| MailHog | http://localhost:8025 | メール確認（開発用） |
| Portainer | http://localhost:9000 | Docker管理 |

## 🔑 デフォルト認証情報

| サービス | ユーザー名 | パスワード |
|---------|-----------|------------|
| Neo4j | neo4j | lifeguardian2024 |
| PostgreSQL | lifeguardian | lifeguardian2024 |
| n8n | admin | lifeguardian2024 |

**⚠️ 注意**: 本番環境では必ずパスワードを変更してください！

## 🎯 基本的な使い方

### サービスの起動・停止

```bash
# 起動
make up

# 停止
make down

# 再起動
make restart
```

### ログの確認

```bash
# 全サービスのログ
make logs

# 特定サービスのログ
make logs-backend
make logs-frontend
make logs-neo4j
```

### データベース操作

```bash
# バックアップ
make db-backup

# Cypher Shellに接続
make cypher-shell
```

### 開発作業

```bash
# バックエンドコンテナに接続
make shell-backend

# テスト実行
make test

# リント実行
make lint
```

## 🔧 トラブルシューティング

### ポートが使用中の場合

```bash
# 使用中のポートを確認
lsof -i :3000
lsof -i :7474

# プロセスを終了
kill -9 <PID>
```

### 権限エラーの場合

```bash
make fix-permissions
```

### 完全リセット

```bash
# データも含めて完全リセット
make reset
```
