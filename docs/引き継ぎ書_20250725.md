## 重要な注意事項

1. **Neo4j認証**: 現在パスワードなしで動作。本番環境では必ず認証を有効化すること。

2. **環境変数**: `.env`ファイルに重要な設定が含まれている。本番環境では適切に変更すること。

3. **データ永続性**: Dockerボリュームでデータを保存。`docker-compose down -v`を実行するとデータが削除される。

4. **開発環境**: Windows環境で`make`コマンドは使えない。直接`docker-compose`コマンドを使用。

## コマンドチートシート

```bash
# 環境起動
docker-compose up -d

# ログ確認
docker-compose logs -f [サービス名]

# 特定サービスの再起動
docker-compose restart [サービス名]

# バックエンドのみ再ビルド
docker-compose up -d --build backend

# Neo4jシェル接続
docker-compose exec neo4j cypher-shell

# 環境停止
docker-compose down
```

## API使用例

### Person作成
```bash
curl -X POST http://localhost:3001/api/persons \
  -H "Content-Type: application/json" \
  -d '{
    "name": "田中花子",
    "birthDate": "1945-03-20",
    "currentHealthStatus": "安定",
    "communicationAbility": "会話可能"
  }'
```

### 全Person取得
```bash
curl http://localhost:3001/api/persons
```
